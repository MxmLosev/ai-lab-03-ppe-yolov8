### Семантика пар «каска/без каски»

Пары вида Hardhat/NO-Hardhat размечены как **два отдельных положительных класса объектов с собственными рамками**: одна и та же область (голова) получает рамку с классом Hardhat, если на ней есть каска, и рамку с классом NO-Hardhat, если каски нет. Отрицательный класс — это НЕ «отсутствие положительного объекта» (такая семантика требовала бы фоновых изображений и оценивалась бы на уровне сцены, а не рамок). Обе сущности аннотируются рамками, присутствуют в mAP, и их путаница отслеживается в матрице ошибок. Правило разметки для «выпрямления»: NO-* рамки ставятся только на видимой части тела/лица, где отсутствие СИЗ достоверно видно.

## Источник кадров и групповое разбиение

- Кадры происходят из нескольких источников: видео YouTube (2 ролика), серии кадров мобильных съёмок (`IMG_*_mp4-*`, `movie-on-*`, `construction-*`) и импорты из открытых Roboflow-проектов (person-detection, safety vests, excavators, MIT indoor scene и др. — полный список в README Roboflow `data/_pool`).
- **Правило группировки**: группа = префикс имени файла до маркера расширения (`_jpg`, `_png`, `_mp4`, `_mov`, `.rf.`) с обрезкой хвостового индекса кадра. Так, 5 аугментированных версий одного исходного кадра Roboflow (`<base>_jpg.rf.<hash>.jpg`) попадают в одну группу; соседние кадры одной видеосерии (`youtube-*`, `construction-*`, `image_*`, `img_*`) также объединяются в одну группу.
- **Разбиение 70/15/15** выполнено скриптом `src/prepare_split.py` (seed=42) по группам, а не по кадрам: целевые объёмы train 560 / val 120 / test 120 изображений, минимальное покрытие каждого класса в каждой части (≥25 экземпляров в train, ≥10 в val и test). Фактически: 821 изображение (570/124/127) из 2801 доступного; крупные группы-видео не делятся между частями.
- Проверка утечек (`src/check_leaks.py`): совпадение имён, md5-хэшей содержимого и пересечение групп между частями — **не обнаружены** (`reports/leak_check.json`).
- Манифест разбиения (файл → группа → часть): `data/split_manifest.json`.

## Предобработка исходного набора (Roboflow v28)

- Автоориентация по EXIF, ресайз до 640×640 (stretch);
- Версия v28 уже содержит аугментации: горизонтальный флип 50%, случайный кроп 0–20%, поворот ±12° — по 5 версий каждого исходного кадра;
- Собственная санитизация при разбиении (`src/common.py::sanitize_boxes`): рамки, выходящие за границы изображения, обрезаются до границ, полностью ушли за кадр — удаляются (фактически на выбранной подвыборке: 0 обрезано, 0 удалено — координаты уже в границах).

## Ограничения набора

- **География и условия**: в основном англоязычные страны, дневные съёмки, часть кадров — CCTV-качество;
- **Ракурсы**: преимущественно статичные камеры и ручные горизонтальные съёмки; редко — виды сверху;
- **Состав людей**: разные расстояния до камеры, плотные толпы на уличных сценах (мелкие объекты), одиночные рабочие крупным планом;
- **Постановочные кадры**: есть (демонстрационные фото СИЗ), плюс нерелевантные доменные кадры (интерьеры MIT indoor, велосипеды, городские сцены) — они играют роль фоновых негативов для подавления ложных срабатываний, но размывают доменную специфику;
- **Класс Mask** — медицинская защитная маска (эпоха COVID), не респиратор стройплощадки;
- Аугментации v28 создают почти дубликаты одного кадра — учтены группировкой (утечка исключена проверкой), но сохраняют внутригрупповую избыточность;
- 8 изображений без рамок (фон) — оставлены как негативы.
