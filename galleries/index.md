# Галереи ошибок (модель E2, imgsz 960, рабочий порог 0.35)

Сгенерировано `src/error_galleries.py`: предсказания на замороженном тесте (127 изображений), жадное IoU-сопоставление 0.5. Зелёные рамки — эталон (G:), красные — предсказания (P:). По 8 примеров на тип; в подписи — имя источника и причина.

| Файл | Тип ошибки | Что показывает |
|---|---|---|
| `1_high_conf_false_positives.png` | Ложные срабатывания с высокой уверенностью (conf ≥ 0.5 без пары) | доменный сдвиг сцены, пересветы, виды сверху |
| `2_missed_critical.png` | Пропуски критичного класса NO-Hardhat | плотные толпы мелких объектов, нерелевантные сцены с разметкой голов прохожих |
| `3_low_iou_matches.png` | Сопоставленные рамки с IoU < 0.7 | неточная локализация, расхождения стиля рамок источников |
| `4_class_confusion.png` | Путаница похожих классов (сопоставление без класса, IoU ≥ 0.5) | Person↔NO-Safety Vest, Hardhat↔NO-Hardhat, machinery↔vehicle |
| `5_small_and_occluded.png` | Мелкие (площадь < 0.006 кадра) и перекрытые объекты, кроп вокруг объекта | предельные размеры конусов/голов, размытие |
| `6_suspected_gt_errors.png` | Подозрения на ошибки эталона: дубликаты GT (IoU ≥ 0.7), гигантские рамки (площадь > 0.8), класс-vs-предсказание (conf ≥ 0.45, IoU ≥ 0.55) | кандидаты на ревью разметки |

Разбор 12 конкретных примеров с атрибуцией причин — `reports/lab03-report.md`, раздел 6.
